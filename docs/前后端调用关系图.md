│       │                                                                  │

│       │    └──→ 命中? → return {match_type: "exact", answer: "..."}      │
│       │                                                                  │

│       │         │  │    ├──→ _call_with_tools() → LLM API               │

## 十二、服务层内部调用关系

```
RequirementAnalyzer ─────┬──→ LLMService.chat_completion()        → LLM API (8种)
 (核心引擎)                │    LLMService.chat_with_tools()        → LLM API + Function Calling
                          │
                          ├──→ SQLValidator.execute_sql_on_all()   → ThreadPoolExecutor → 6种数据库
                          │    SQLValidator.execute_test_sql_on_all()
                          │
                          ├──→ function_tools.execute_tool()
                          │    ├─ "execute_sql"      → SQLValidator
                          │    ├─ "execute_sql_test"  → SQLValidator
                          │    └─ "web_search"        → WebSearchConfigManager → 搜索引擎API
                          │
                          ├──→ SkillsConfigManager.get_prompt_for_scene()
                          │    SkillsConfigManager.render_prompt()
                          │
                          └──→ PDFParser / DocumentParser          → 文件系统

AnalysisTaskManager ──────→ threading.Thread
                              └──→ RequirementAnalyzer.analyze_requirement() (串行for循环)

BidAnswerGenerator ───────→ LLMService.chat_completion()           → LLM API
BidDocumentParser ────────→ PDFParser                              → 文件系统
```
