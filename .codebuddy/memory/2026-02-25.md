- **`llm_service.py`**: 
  - `chat_completion()` 分发逻辑中添加 `ollama` 路由
  - 新增 `_call_ollama_api()` 方法，使用 Ollama 的 OpenAI 兼容接口（`/v1/chat/completions`）

  - 无需 API Key（如有反向代理鉴权也支持传递）
  - 连接失败时给出友好的 Ollama 未启动提示
  - `model_context_limits` 中添加 `ollama: 32000`
- **`llm_main.html`** + **`chat_doc.html`**（两个页面都有 LLM 配置 UI，需同步修改）:
  - 模型类型下拉框添加 `Ollama (本地)` 选项
  - modelOptions/llmModelOptions 添加 Ollama 预设模型列表
  - onModelTypeChange/onLLMModelTypeChange 中 Ollama 特殊处理：下拉预设 + 自定义输入模式、API Key placeholder 提示"本地部署无需填写"
  - saveConfig/saveLLMConfig 中 Ollama 类型不要求必填 API Key
- **`llm_routes.py`**:
  - `create_llm_config()` Ollama 类型免除 api_key 必填校验
